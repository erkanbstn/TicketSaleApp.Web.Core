# Bilet satışı

Uçuş, koltuk ve bilet satışını yöneten web uygulaması.

## Ne var

Uçuş, koltuk, bilet ve kullanıcı için ayrı controller'lar vardır. Giriş `AuthController` içindedir.

## Çalıştırma

```powershell
dotnet run --project TicketSaleApp
```

## Yığın

.NET 8, ASP.NET Core MVC, Entity Framework Core ve SQL Server.
